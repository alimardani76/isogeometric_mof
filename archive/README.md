# Historical and noncanonical assets

This directory is reserved for historical or superseded publication assets that remain useful for provenance but should not be mistaken for the canonical paper-generation workflow.

Examples include:

- superseded figure renderer variants;
- historical release audits;
- obsolete manuscript-facing renderers;
- intermediate documentation that explains provenance but is not part of the current reproduction path.

## Canonicality rule

A final paper figure should have one clearly identified canonical renderer and one clearly identified source package.

Historical files may be preserved here, but they must be labeled as noncanonical and must not share ambiguous publication-facing names with the active renderer.

No historical renderer is moved here merely because its filename contains an older version number. Canonical selection must be based on the finalized figure packet and verified source/output provenance.
