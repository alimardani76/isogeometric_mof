# Figures

This folder contains generated files found under `Step 3 results/main_figures` and `Step 3 results/si_figures`.

The main set contains Figures 1-6 in PDF, PNG, and SVG formats. The supplementary set contains Figures S01-S03 in PDF and PNG formats. Associated run manifests and source hashes are preserved under `../provenance/`.

The files are included as verified paper assets, not as evidence of an open-content license. Public release requires a rights/licensing decision. Figure 5 cannot be regenerated from this draft alone because its selected CIF inputs were excluded.
